Install `hxn-assets` for typed asset declarations, asynchronous loading, HTTP(S)/WS(S) streams and opt-in knowledge metadata. Install `hxn-file` alone for scoped bundled files, saves, preferences and URI I/O. Both use core `hxn.Log` from hxn 0.3.9.

The packages include desktop, iOS, Android, threaded Ash wasm and both Emscripten modes, with package-specific skills and dependency notices. The asset package includes its `hxn assets` CLI plugin. The optional native KyuGraph adapter remains source-only and is not linked into either haxelib.

The knowledge example combines lore, quest progress, NPC relationships and spatial queries. Connected graph adapters, schema migrations, hosted service and CRDT synchronization remain open work. Physical-device transitions and Safari coverage are not claimed.
